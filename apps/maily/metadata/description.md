Maily is the Universal Temporary Email Gateway & REST API Platform.

Taming the disposable email zoo under a single high-performance REST API, modern async Python SDK, and dark-mode web console.

## ✨ Features

- **8 Integrated Temp Mail Providers** — aggregates Mail.tm, TempMail Plus, Temp-Mail.io, NoopMail, DispoEmail, AnonymMail, Temp.tf, and Gmail OAuth2.
- **⚡ 1-Line Verification Code Extraction** — automated extraction of 4–8 digit OTP codes and confirmation links for Playwright, Pytest, and QA bots.
- **🖥️ Dark-Mode Web Dashboard** — modern responsive admin console with live charts and real-time message inspection.
- **🔑 Scoped API Keys** — multi-tenant token management with granular permissions.
- **🧹 Zero-Maintenance DB Sweeper** — automatic retention sweeps and SQLite WAL defragmentation.
