# LibreDB Studio

Self-hosted, browser-based database IDE for 16 engines

LibreDB Studio is an open-source (MIT), self-hosted, browser-based database IDE and client. It connects to 16 engines including PostgreSQL, MySQL, Oracle, SQL Server, SQLite, libSQL, DuckDB, MongoDB, Redis, Couchbase, ClickHouse, Druid, Elasticsearch, OpenSearch, Apache Trino and Apache Cassandra. The MIT build ships SSO (OIDC), RBAC, query audit logs, ER diagrams, EXPLAIN visualization and schema comparison. Optional AI assistance can use Gemini, OpenAI or a local Ollama model so data stays on your network.
