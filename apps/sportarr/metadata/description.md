## Sports event manager for Usenet and BitTorrent

Sportarr is an event manager for sports fans. It monitors the leagues and
events you follow, grabs broadcasts through your Usenet and BitTorrent
download clients, then sorts and renames them into a clean season/episode
layout that Plex, Emby, Jellyfin and Kodi understand.

### Current Features

- Follow whole leagues or individual events across dozens of sports
- Automatic grabbing through your existing download clients (SABnzbd,
  qBittorrent, Transmission, Deluge, NZBGet and more)
- Quality profiles with automatic upgrades when a better release appears
- Calendar of upcoming events and a full wanted/missing view
- Season/episode style naming for media server compatibility, with
  metadata agents for Plex, Jellyfin, Emby and Kodi
- IPTV DVR-style recording for live events
- Works with Prowlarr for indexer management

### First steps

Add a root folder under Settings > Media Management, connect a download
client and an indexer, then add your first league. The web UI listens on
port 1867.
