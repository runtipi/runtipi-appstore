# Quire Ink

A blog you host yourself, and an AI agent can run it for you. One process, two SQLite
files, no cloud account anywhere in the path.

## What you get

- A real editor over Markdown: tables, video, footnotes, callouts, mathematics. Images are
  resized for every screen on upload.
- A composed front page or a plain post list, six colour palettes in light and dark, four
  reading fonts, and a book mode that sets a post in two columns on paper.
- Newsletters over your own SMTP, comments with a spam gate that needs no account anywhere,
  cookie-free analytics, full-text search, scheduled publishing, series.
- Importers for WordPress, Ghost, Substack and Medium: posts, pages and images come across,
  old URLs become redirects.
- An MCP server built in, so Claude or any MCP client can draft, publish, moderate and
  report on the blog through the same rules the admin follows.
- Readers download 3.9–10.4 KB of JavaScript and nothing from any third party.

## First run

The blog has no owner until you claim it. Open the app's logs right after installing — it
prints a one-time claim link at every start. Open that link, create your account, and the
rest happens in the browser (password, authenticator QR, recovery codes).

The interface speaks eleven languages, and the first question of setup is which one your
blog speaks.
